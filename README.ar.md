# Smart Route لسوليد ووركس (ملخص بالعربي)

إضافة بتخطط مسار الكابل حوالين **الشكل الفعلي للمجسمات**، وبتديك **معاينة 3D لحد 3 بدائل** (أقصر / زوايا قائمة / مسافة أمان أكبر)،
وبتنشئ الراوت الحقيقي في Routing، وبعد كده **بتتحقق** من نصف قطر الانحناء والمسافات والتداخل.

## التسطيب (للمستخدم)
1. نزّل `SmartRoute-Setup-x.y.z.exe` من صفحة Releases.
2. شغّله (محتاج صلاحيات Admin) وكمّل Next لحد Finish.
3. افتح سوليد ووركس: Tools > Add-Ins وعلّم على **Smart Route** و **SOLIDWORKS Routing**.

بعد كده بتفضل في البرنامج. للتحديث: زر **Updates** أو تلقائيًا كل يوم، والتحديث بيتسطّب لما تقفل سوليد ووركس.

## رفع المشروع على GitHub (مرة واحدة)
```powershell
.\tools\init-github.ps1 -Name smart-route      # بيعمل Repo عام ويرفع كل الـ commits والـ tags
.\tools\release.ps1 -Version 0.3.0             # بيبني المُثبّت وينشر Release
```
لازم الـ Repo يكون **Public** عشان التحديث التلقائي يقدر يقرا الإصدارات.

## كل إصدار جديد
عدّل الكود، ضيف قسم في `CHANGELOG.md`، وشغّل: `.\tools\release.ps1 -Version 0.4.0`.

المشروع لسه Beta: اتجرب بالاختبارات الآلية بس، ولسه ما اتجربش على سوليد ووركس حقيقي. ابدأ بزر **Scan Routes** وابعت `scan.txt` و `smartroute.log`.
